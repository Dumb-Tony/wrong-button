# Standalone M1

Open index.html directly for offline play, or use the public GitHub Pages URL in the root README. All game code, styles, Canvas geometry and generated sound are embedded.

For regression checks, serve this directory with a static HTTP server and open checks.html. Example: `python -m http.server 8767 --bind 127.0.0.1` from this directory. Tests are developer-only and not deployed. They reveal the solution and write test records on the local test origin; use a separate browser profile if preserving your local practice records matters.

See ../../docs/TRANSITIONS_M1.md for authored rules and ../../docs/PLAYTEST_LOG.md for evidence and outstanding gates.
